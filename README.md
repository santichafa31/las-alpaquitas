# Las Alpaquitas - Calculadora web

## Requisitos
- Python 3.10 o superior

## Cómo ejecutar
1. Descomprime el proyecto.
2. Abre una terminal dentro de la carpeta `las_alpaquitas`.
3. Ejecuta:
   python -m pip install -r requirements.txt
4. Luego:
   python app.py
5. En la computadora abre:
   http://127.0.0.1:5000

## Abrir desde celular o tablet en la misma red Wi-Fi
Cuando ejecutes `python app.py`, usa la dirección IP local de la computadora seguida de `:5000`, por ejemplo:
   http://192.168.1.10:5000

Nota: puede ser necesario permitir Python en el firewall de Windows.

## Funciones
- Precio y cantidad de hot dogs.
- Precio y cantidad de batidos.
- 10% de descuento independiente para cada producto.
- Se puede activar en uno, en ambos o en ninguno.
- Subtotal, descuento y total.
- Diseño responsive para celular, tablet y computadora.
